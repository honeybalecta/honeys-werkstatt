Einstellungen

GitHub-Zugang

So legst du ihn an

  1. Auf GitHub einen „Fine-grained token“ anlegen (Knopf unten). Du kannst auch denselben Token wie auf dem Handy nehmen.
  2. Repository access: „All repositories“ – dann klappen auch künftige private Apps.
  3. Permissions › Repository › Contents: „Read-only“. Mehr braucht es nicht.
  4. Token kopieren und hier einfügen. Er liegt danach in der Windows-Anmeldeinformationsverwaltung.
